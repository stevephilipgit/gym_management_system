================================================================================
TROUBLESHOOTING COMMON ISSUES
================================================================================

ISSUE 1: "Failed to fetch today's data" error
SOLUTION:
  • Check backend is running: Invoke-WebRequest -Uri "http://localhost:5000"
  • Verify /today endpoint exists in financeRoutes.js
  • Check browser console (F12) for network errors
  • Restart backend server

ISSUE 2: Old data showing in "Today" view
SOLUTION:
  • Hard refresh page (Ctrl+Shift+R)
  • Clear browser cache
  • Wait for auto-refresh (30 seconds)
  • Check server clock is correct

ISSUE 3: Charts empty after selecting custom range
SOLUTION:
  • Verify date range has data
  • Check /income endpoint works independently
  • Try different date range
  • Look at FinanceLog collection for records

ISSUE 4: Midnight reset not working
SOLUTION:
  • Verify server time is correct
  • Check that 4 AM is set as business start time
  • Midnight check runs every 60 seconds
  • Manually refresh page to trigger reset

ISSUE 5: Performance slow (queries taking >500ms)
SOLUTION:
  • Run createIndexes.js to verify indexes
  • Check MongoDB connection
  • Check for large historical data (>1M records)
  • Monitor server CPU/memory
