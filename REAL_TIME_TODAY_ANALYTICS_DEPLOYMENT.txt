NEW ENDPOINT: GET /api/finance/today
────────────────────────────────────

Request:

  Headers: Cookie: gym_admin_token=<jwt>

  },

      "amount": 2500
    }
  ],
  "memberCountsByTraining": {
    "Weight Loss": 3,
    "Weight Gain": 2,
    "Transformation": 1
  },
  "timestamp": "2026-03-02T14:35:42.123Z",
  "period": "today"
}

BUSINESS HOURS LOGIC
────────────────────

Time          Business Day Treated As
─────────────────────────────────────
12:00 AM-3:59 AM  Previous day (2026-03-01)
4:00 AM-11:59 PM  Current day (2026-03-02)

Why?
  Gym opens at 4:00 AM
  Late-night registrations belong to "today"
  Data from midnight-3:59 AM belongs to "yesterday's" ledger

FRONTEND POLLING
─────────────────

Mechanism: setInterval (JavaScript)
Frequency: Every 30 seconds
Fallback: Every 1 minute checks for date change
Cleanup: Intervals cleared on component unmount
No state on server: Fully stateless

TROUBLESHOOTING QUICK REFERENCE
================================================================================

ISSUE: Dashboard shows "Loading..." forever
FIX: 
  • Hard refresh (Ctrl+Shift+R)
  • Check backend: Invoke-WebRequest -Uri "http://localhost:5000"
  • Restart backend: Get-Job | Stop-Job; npm start (in backend dir)

ISSUE: "Custom Range" shows old data
FIX:
  • Clear browser cache
  • Try dates with known transactions
  • Check /income endpoint is working

ISSUE: Today's data shows $0 when should have transactions
FIX:
  • Verify transactions created after 4 AM
  • Check timezone matches server
  • Create a test transaction and watch for update

ISSUE: Cards and charts don't load
FIX:
  • Check browser console for API errors
  • Verify authentication cookie is set
  • Restart backend server

ISSUE: Real-time update not happening
FIX:
  • Check network tab in DevTools (F12)
  • Verify polling requests hitting backend
  • Wait 30 seconds for auto-refresh
  • Manually refresh page
